# Domain boundary

Quiz questions, sessions, answers, scoring and session history belong here when their
rules are agreed. No FastAPI, Pydantic HTTP schemas or SQLAlchemy imports are allowed.
No entities/repository signatures have been invented during initialization.
Future application use cases depend on these pure entities and repository protocols;
infrastructure implements those protocols. Domain errors and resource-not-found mapping
will be added with the first actual business use case, not an unused exception hierarchy.
